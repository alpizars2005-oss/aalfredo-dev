# Personal Portfolio

This is my personal portfolio website, built to present my projects, skills, and current learning path.

The site is available in both English and Spanish and was created with HTML, CSS, and vanilla JavaScript.

## Features

- English and Spanish language selection
- Responsive design
- Project showcase
- Skills and contact sections
- Links to GitHub and LinkedIn
