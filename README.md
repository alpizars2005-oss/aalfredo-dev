# Angel Alfredo | Personal Portfolio

This is my personal portfolio website. I built it with HTML, CSS, and vanilla JavaScript to present my learning path, projects, skills, and contact options.

The goal of this project is to keep a simple but clean portfolio that shows my current progress as a Computer Systems Engineering student and aspiring Full Stack Developer.

## Live Website

https://alpizars2005-oss.github.io/aalfredo-dev/

## Features

- English and Spanish language selection
- Responsive layout for desktop and mobile
- Project cards with repository links
- Skills and learning focus sections
- Contact buttons
- CV download button that changes depending on the selected language
- Published with GitHub Pages
